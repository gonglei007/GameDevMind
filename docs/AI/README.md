## 重点资料：《AI游戏开发》

**[阅读《AI游戏开发》六篇实践手册](../AI游戏开发/README.md)**

手册围绕人工决策、AI 执行与实践验证持续积累，覆盖协作原则、系统架构、开发迭代、可复用提示词、项目复盘和经验维护。个人经验保留原意，整理补充与外部资料分别标注，适合在项目推进中反复查阅。

从具体任务进入时，可使用手册的[任务导航](../AI游戏开发/README.md#按任务查找)；需要为当前代码设定优化任务时，可查阅[代码设计优化提示词](../AI游戏开发/04.可复用提示词.md)。

## 按目标选择阅读顺序

- **开始用 AI 推进项目**：[《AI游戏开发》](../AI游戏开发/README.md) → [AI Coding 总览](../../mds/阅读说明.md#ai-coding-总览) → 按项目需要选用[工程模板与示例](#ai-coding-指南模板与示例)。
- **复核一条具体建议**：[AI 协作记录](../../ai-cases/README.md) → 从[文档索引](../../INDEX.md)查阅对应技术章节 → 在当前项目中验证。
- **研究某类应用**：按[基础](../../mds/1.基础能力/1.3.2.人工智能.md)、[游戏运行时](../../mds/3.研发能力/3.3.4.游戏AI系统.md)、[生产](../../mds/4.生产能力/4.1.2.AI助力游戏生产.md)或[运营](../../mds/6.运营能力/6.2.6.AI助力游戏运营.md)专题进入，再结合[手册](../AI游戏开发/README.md)的方法组织任务与验收。
