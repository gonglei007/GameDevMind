# AI 研发与应用

[返回仓库首页](../../README.md)

这里汇集 GameDevMind 中两类 AI 资料：用 AI 辅助游戏研发、内容生产与运营的方法，以及人工智能基础和游戏运行时 AI 技术。按当前任务选择入口。

## 重点资料：《AI游戏开发》

**[阅读《AI游戏开发》六篇实践手册](../AI游戏开发/README.md)**

手册围绕人工决策、AI 执行与实践验证持续积累，覆盖协作原则、系统架构、开发迭代、可复用提示词、项目复盘、经验维护与能力共享。个人经验保留原意，整理补充与外部资料分别标注，适合在项目推进中反复查阅。

从具体任务进入时，可使用手册的[任务导航](../AI游戏开发/README.md#按任务查找)。

## 按目标选择阅读顺序

- **开始用 AI 推进项目**：先看手册的[第一次怎么用](../AI游戏开发/README.md#第一次怎么用)，再按[任务导航](../AI游戏开发/README.md#按任务查找)推进，按需选用[工程模板与示例](#ai-coding-指南模板与示例)。
- **复核一条具体建议**：[AI 协作记录目录](../../ai-cases/README.md) → 从[文档索引](../../INDEX.md)查阅对应技术章节 → 在当前项目中验证。
- **了解 AI 技术与游戏运行时系统**：[人工智能基础](../../mds/1.基础能力/1.3.2.人工智能.md) → 按需查阅[游戏 AI 系统](../../mds/3.研发能力/3.3.4.游戏AI系统.md)。
- **用 AI 辅助内容生产或运营**：进入[生产](../../mds/4.生产能力/4.1.2.AI助力游戏生产.md)或[运营](../../mds/6.运营能力/6.2.6.AI助力游戏运营.md)专题，再结合[手册](../AI游戏开发/README.md)的方法组织任务与验收。

## AI Coding 指南、模板与示例

- [AI Coding 总览](../../mds/阅读说明.md#ai-coding-总览)：结合知识图谱描述需求、约束与验证方法，理解各技术章节中的 AI Coding 指南。
- [代码设计优化提示词](../AI游戏开发/04.可复用提示词.md#代码设计优化目标提示词)：复制完整代码块，替换项目、范围与验收等占位字段，连同项目材料提供给 AI，再按要求审查、验证和分批提交。
- [游戏开发项目规则模板](../../.cursorrules.example)（Cursor）：按文件内说明复制并填写项目字段，用于约束项目类型、编码与协作方式。
- [项目记忆模板](../../CLAUDE.md.example)（Claude Code）：按文件内说明复制并填写项目背景、架构、规范和常用操作，帮助 AI 接手已有工程。
- [AI 辅助编程配套示例](../../code/artile-sample-code/01-foundation/07-ai-coding/README.md)（Python）：可直接阅读并复制功能实现、调试、重构与审查模板；运行脚本会输出提示词，再将提示词提供给 AI 继续协作。
