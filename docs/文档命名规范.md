# 文档命名规范

本规范与 [CONTRIBUTING.md](../CONTRIBUTING.md) 配套，适用于 `mds/` 下新增或重命名文档。

## 文件命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 能力模块入口 | `{模块号}.{模块名}.md` | `1.基础能力.md` |
| 子分类入口 | `{模块号}.{子号}.{子类名}.md` | `1.1.编程语言.md` |
| 叶子文档 | `{模块号}.{子号}.{序号}.{主题名}.md` | `1.1.1.编程语言基础概念.md` |
| 专题 | `mds/topics/{主题名}.md` | `topics/游戏开发新人.md` |
| 归档/扩展 | `x-{编号}.{主题}.md` | `x-1.开发技术.md` |

**规则：**

- 使用**中文**主题名，与现有文档保持一致
- 编号使用半角数字 + 点号，**不要**在编号段之间插入空格
- 扩展名统一 `.md`，文件名中避免 `/ \ : * ? " < > |`

## 目录结构

```
mds/
├── {N}.{模块名}/           # N = 1～6
│   ├── {N}.{模块名}.md     # 模块入口
│   ├── {N}.{子}.{子类}.md  # 子类入口（可选）
│   └── {N}.{子}.{序}.{主题}.md
├── topics/                 # 跨模块专题
└── 阅读说明.md             # 全局阅读指南
```

## 文档结构（叶子文档）

参考 [template/z.模板.md](../template/z.模板.md)：

1. `## 标题` + 简介 `<p>...</p>`
2. `**关键词:**` / `**标签:**`
3. （可选）`## 目录`
4. 正文：表格化「是什么 / 问题 / 要点」
5. （可选）AI Coding 指南表格
6. （可选）`## 延伸实践`
7. `## 更多资料`

### 正文内部层级

文档标题使用 `##`，正文应进一步用“领域分组 → 知识主题”组织内容，避免把不同层级的概念全部平铺在同一级标题下：

```text
## 文档标题
## 领域分组
### 知识主题
#### 步骤、变体或实现细节（必要时使用）
```

**规则：**

- 每篇较长正文建议设置 3～7 个 `##` 领域分组；每组包含 2～8 个 `###` 知识主题。
- `##` 用于完整知识领域，例如“关系数据库与 SQL”“资源与加载”；`###` 用于可独立检索的具体主题，例如“事务”“图集”。
- “是什么 / 在哪用”“会遇到哪些问题 / 用什么解决”“要点和思考方向”“AI Coding 指南”等固定信息块保留在 `###` 主题内部，不要全部升级为标题。
- `####` 仅用于步骤、方案变体、算法细节或配置项；通常不超过两层正文嵌套。
- 正文超过约 450 行时，应先检查是否缺少领域分组；一个主题超过约 250～300 行且拥有独立读者或维护边界时，再考虑拆成独立文件。
- 目录优先列出 `##` 领域分组；长文档可以在分组下列出关键 `###` 主题，不必把每个信息块都列入目录。
- 模块入口文档、阅读路径和专题文档可以采用自己的结构，不强行套用叶子文档的技术主题模板。

## 标签字段约定

```
**标签:**<br/>
*等级: 入门|初级|中级|高级, 阶段: 学习|开发|运营, 分类: {模块名}, 角色: 客户端开发|服务端开发*
```

- **等级**：入门 / 初级 / 中级 / 高级（可多选，用 `|` 分隔）
- **阶段**：学习 / 开发 / 运营
- **分类**：与六大能力模块一致；跨层关系通过正文链接和专题路径表达，不在一个文档中填写多个主分类
- **角色**：客户端 / 服务端 / 全栈 / 美术 / 运维 等

## 图片与链接

- 图谱图：`../../exports/{与文档同名的前缀}.png`（相对路径，**不加** `?raw=true`）
- 模块内链接：相对路径，如 `../2.技术能力/2.2.1.网络与通信.md`
- 配套资源：链到 `code/gamedevmind/`、`cases/`、`ai-cases/` 时使用相对路径（从 `mds/` 子目录通常为 `../../code/gamedevmind/...`）

## 可选：YAML Front Matter

新文档**不强制** Front Matter。若需脚本或静态站点消费元数据，可在文首添加：

```yaml
---
title: 编程语言基础概念
category: 基础能力
last_updated: 2026-06-20
---
```

与正文中的 `**关键词:**` / `**标签:**` 保持语义一致即可。
