## 游戏数学 — 配套代码

对应文章：一-04-游戏开发需要哪些数学基础？按场景梳理

### 文章章节 ↔ 示例

| 文章章节 | 本目录 | 说明 |
|----------|--------|------|
| 向量与向量运算 | `game_math.py` | Vector2/3、点积、叉积 |
| 矩阵与变换 | `game_math.py` | TRS 矩阵、向量变换 |
| 几何基础 | `game_math.py` | AABB 碰撞、点到线段 |
| 插值与曲线 | `game_math.py` | Lerp/Slerp、贝塞尔曲线 |

### 运行

```bash
python3 game_math.py
```

纯标准库，无外部依赖。

### 包含内容

| 模块 | 说明 |
|------|------|
| **Vector2/3** | 加减乘除、归一化、长度 |
| **点积 (Dot)** | 视角判定、光照强度 |
| **叉积 (Cross)** | 法线计算、旋转轴 |
| **Matrix4x4** | TRS 变换矩阵 |
| **AABB** | 轴对齐包围盒碰撞 |
| **贝塞尔曲线** | 二次/三次插值 |
| **Lerp/Slerp** | 线性/球面插值 |
