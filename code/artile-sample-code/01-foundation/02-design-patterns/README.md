### 示例列表

| 模式 | 文件 | 语言 |
|------|------|:--:|

| 观察者模式 (事件系统) | `observer.py` | Python |

### 运行

```bash
# C++
g++ -std=c++17 singleton.cpp -o singleton && ./singleton

# Python
python3 observer.py
```
