### 示例

| 示例 | 文件 | 说明 |
|------|------|------|
| 客户端预测 + 和解 + 插值 | `net_sync.py` | 模拟 100ms 延迟下的状态同步全流程 |

### 设计要点

- **客户端预测**: 输入立即生效，不等服务器确认
- **服务器和解**: 服务器发回权威位置 → 客户端校正 → 重放未确认输入
- **实体插值**: 其他玩家在两次服务器快照间线性插值，保证平滑
- **网络模拟**: `NetworkSimulator` 用延迟队列模拟 100ms RTT

### 运行

```bash
python3 net_sync.py
```
